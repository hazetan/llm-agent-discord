# 4. セットアップ手順
- Python仮想環境を構築

- 主要ライブラリをインストール

- 実行スクリプトに権限を付与
`chmod u+x run`

- コマンド実行（tmux推奨）
`./run`


# アップデート履歴(11/09)
- Doker操作の抽象化により分散実行を可能にした．
以前はsubprocessで直接dockerコマンドを叩かせていたため複数のエージェントセッションが走るとプロセスが煩雑になっていた．
-> Doker Pythonライブラリに移行し分散実行可能にした．

- 非同期タスクキューの導入により負荷を分散した．
以前はイベントループ内でエージェントループを並列処理していた．
-> Celery等の専用タスクキューによりDiscordの応答処理とエージェントの推論ワーカーを物理的に分散することでシステムの安定性が向上した．

- ベクターストア（RAG）の統合によりコンテキスト長リソースの最適化を行った．
以前はTroubleshootingMemoryによるエラー解決ナレッジを注入したが，レコード数が増えすぎるとコンテキスト長を圧迫するという問題があった．
-> ベクトルデータベース（RAGアーキテクチャ）の導入により現在直面しているエラーに類似した過去の知見のみを動的に検索・抽出して注入する仕組みに拡張した．
